📱 Installer B Diamond

📱 Méthode 1 : Installation PWA (rapide)

L'application s'installe directement depuis le navigateur

📱 Android (Chrome) :

1. Ouvre le lien de l'application

2. Clique sur le bouton "📱 Installer B Diamond"

3. Confirme l'installation

📱 iPhone (Safari) :

1. Ouvre le lien dans Safari

2. Touche le bouton Partager (⬆️)

3. Choisis "Sur l'écran d'accueil"

🤖 Méthode 2 : Fichier APK (comme Play Store)

Crée un vrai fichier APK Android installable

Étapes pour créer l'APK :

1. Va sur PWABuilder.com

2. Entre l'URL de ton application

3. Clique sur "Generate Package"

4. Choisis "Android"

5. Télécharge le fichier APK

6. Partage le fichier APK aux utilisateurs

🏪 Méthode 3 : Google Play Store

Publication officielle sur Google Play

Conditions :

• Compte Google Developer (25$ une fois)

• Fichier APK ou AAB

• Icône 512x512

• Captures d'écran

• Description de l'application

🍎 Méthode 4 : App Store (iPhone)

Publication sur l'App Store

Conditions :

• Compte Apple Developer (99$/an)

• Application native iOS

• Mac avec Xcode

• Icône 1024x1024
